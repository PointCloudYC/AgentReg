# AgentReg

**AgentReg: Bounding What Tool-Using Agents Can Add to LiDAR Registration**

Chao Yin, Department of Civil and Environmental Engineering, The Hong Kong University of Science and Technology.

AgentReg evaluates when a policy that selects registration tools from their execution diagnostics can improve on a verified fixed schedule. It compares policies using the same cached tool outcomes and measures registration recall and compute cost on KITTI and ETH point-cloud pairs.

## Status

The manuscript is being prepared for journal submission and arXiv posting on 30 November 2026. A preprint link and citation will be added when the preprint is publicly available.

## Code and data release

This repository is currently the project landing page. Code, project-generated data and reproducibility artifacts are planned for release on acceptance of the paper. They are not yet available here.

The release will distinguish regenerating paper tables, replaying policies from cached tool outcomes, and rerunning registration from raw scans. Original KITTI and ETH datasets remain subject to their providers' terms and will not be relicensed by this project.
